# 1. Detect right-clicks on pets with an interaction-entity hitbox

**Context:** Stay/Follow and fetch need to know when a player right-clicks their pet. In 26.3 the `player_interacted_with_entity` advancement trigger only fires when the interaction returns `Success` (checked in `ServerGamePacketListenerImpl`), and right-clicking a plain NoAI enderman returns nothing, so it never fires. The alternatives were polling (sneak-near-pet every tick, like the old pack, which also fired by accident whenever a following pet was nearby) or carrot-on-a-stick/used-item scoreboards (needs a special item in hand). **Decision:** every pet gets an invisible `interaction` entity (tag `ep.hit`, 0.8×3.0) at its feet; `Interaction.interact` returns `Success`, so the advancement fires and runs `ender_pet:click` only on real clicks. **Why:** event-driven (zero per-tick cost), works with any item in hand, and makes commands deliberate. Cost: the hitbox must be moved with the pet (done in `follow`), re-created if missing, and garbage-collected when its pet is gone (both in `loop`); it also swallows right-clicks on blocks directly behind a pet.
