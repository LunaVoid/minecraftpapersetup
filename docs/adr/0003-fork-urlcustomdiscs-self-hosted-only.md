# 0003 — Fork URLCustomDiscs and strip it to self-hosted mode

**Context:** Custom music discs come from the third-party URLCustomDiscs plugin (v2.7.2). In its default API mode every `/customdisc create` uploads audio to the author's server (`167.235.148.137`), which runs yt-dlp, builds the resource pack and hosts it; that server's YouTube downloader broke and we can't see or fix it. The plugin's in-game side works fine on 26.3 (a local MP3 disc played on production). Alternatives: keep upstream and just set `pluginUsageMode: self-hosted` (still ships the API client and a default pointing at the author's IP), reimplement the author's API ourselves (another service to run for no gain), or write our own plugin (rebuilds what already works). **Decision:** vendor the plugin source into `plugins/urlcustomdiscs/`, delete API mode and `RemoteApiClient` so it cannot contact the author's server, default to self-hosted mode with the pack on the shared data volume, and build/release the jar from this repo like our datapacks. **Why:** smallest diff that guarantees the code on our server is code we've read; upstream fixes can still be cherry-picked. Costs: we own merging upstream changes; license is CC-BY-NC 4.0, so this stays non-commercial and keeps attribution plus a note of our changes.
