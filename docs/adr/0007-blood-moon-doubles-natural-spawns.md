# 7. Blood Moon adds mobs by cloning natural spawns, not by summoning near players

**Context:** a datapack can't change mob spawn rates, so "more mobs" means summoning extras ourselves. Summoning at computed spots near players needs our own spawn-rule logic (light level, solid floor, headroom, not inside bases) and would get it wrong in ways players notice, like zombies inside a lit house. **Decision:** while a Blood Moon is up, each new Overworld hostile with `Paper.SpawnReason` `NATURAL` is checked once (tagged `bm.seen`), buffed, and with a 50% chance cloned on the same spot. **Why:** vanilla already decided that spot is a valid spawn, so clones only appear where mobs could anyway; the NBT read happens once per new mob, never per tick. Cost: it relies on Paper's `Paper.SpawnReason` field, so on a non-Paper server no mob would qualify and the Blood Moon would be cosmetic only. Upgrade path if it isn't scary enough: raise the clone chance or clone twice, don't add our own placement.
